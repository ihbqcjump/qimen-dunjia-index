# 可公开转载的子集（sources/）

本目录只收录索引库中许可状态明确、可以公开转载的那一小部分。其他 46 条左右的资料只保留在根目录的索引文件（index.json / index.csv / index.md）里，只记来源和书目，不在这里放正文、PDF 或课程文件。

收录标准（以 2026-10-27 核实为准）：

- `open_license`：来源页面明确写了开源 / CC 许可。
- `public_domain`：原著为明代作品、清代收入《四库全书》，现代点校、注释、译文不在此列。

没有收录的内容：

- 19 条 `copyrighted_do_not_rehost` 的现代商业作品（书、教材、课程、小说等）。
- 27 条版权状态 `unknown` 的资料，包括很多只在聚合站、Scribd、网盘页出现的条目。
- 8 条付费资料的正文。
- 任何二进制 PDF 文件：本仓库通过 GitHub 的文本快照推送，只能推送 UTF-8 文本文件，PDF 二进制文件不适合这样推送。CC-BY 论文的 PDF 请用 `fetch-open-sources.sh` 或下面的链接自行下载，下载后请保留原许可声明。

文件说明：

- `open-licensed/research-paper-ccby.md`：1 篇 CC-BY 4.0 研究论文的元数据、署名、许可和直接下载链接（索引第 47 条）。
- `public-domain/dunjia-yanyi.md`：明代程道生《遁甲演义》的来源、卷目和获取方式（索引第 21、27 条）。正文请用脚本从维基文库获取，不要把其他网站的现代整理本当成原文。
- `open-source-repos.md`：8 个开源排盘仓库的清单，含许可、原地址和克隆命令。代码没有复制进本仓库，请按各仓库的许可条款使用，保留原许可声明。
- `fetch-open-sources.sh`：只下载上面这部分公开内容的脚本，不下载任何付费或版权不明的资料。运行前请先看脚本里的注释和链接。

更新时请同步更新本说明和根目录索引里对应条目的 notes，不要把新找到的版权不明资料直接放进本目录。
